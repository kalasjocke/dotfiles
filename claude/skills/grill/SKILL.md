$ARGUMENTS

Interview me about every aspect of this plan until we agree on each decision.
Resolve the decisions one at a time, starting with the ones others depend on.
Ask one question at a time, and give your recommended answer with each.
If the code can answer a question, look it up instead of asking.
Don't edit anything while grilling.
When no decisions are left, list them and ask before implementing.
